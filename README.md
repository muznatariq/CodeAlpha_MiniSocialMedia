#MiniSocialMediaPlatform
This project is a lightweight, full-stack web application designed to demonstrate the fundamentals of a social media system. It connects a clean front-end user interface with a robust back-end server and a persistent database.
Key Features Implemented:
User Profiles: Structured data modeling for users with support for follower tracking.
Post & Interaction System: Users can create posts, which are stored and displayed in a feed. Users can also interact with these posts through likes and comments.
Like/Follow System: Backend logic to manage user-to-user relationships and interaction counts.
Full-Stack Architecture: * Frontend: HTML5, CSS3, and JavaScript (using Fetch API for asynchronous communication).
Backend: Node.js with Express.js to handle API requests and routing.
Database: MongoDB with Mongoose ODM for structured data storage of users, posts, comments, and followers.
